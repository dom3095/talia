# Codice di condotta

TALIA adotta il [Contributor Covenant, versione 2.1](https://www.contributor-covenant.org/it/version/2/1/code_of_conduct/).
In sintesi: rispetto per tutte le persone, nessuna molestia o discriminazione,
critiche rivolte alle idee e al codice e mai alle persone.

Due punti in più, specifici di questo progetto:

- **Niente accuse a persone o enti reali** nelle issue, nelle PR o nelle
  discussioni. Si parla di atti e di anomalie da verificare, non di colpevoli.
- **Niente dati personali** di terzi: nomi, documenti, contatti, anche se
  pubblicati in un atto.

Per segnalare un comportamento scorretto scrivi al maintainer del repository
tramite il profilo GitHub [@dom3095](https://github.com/dom3095). Le
segnalazioni sono trattate con riservatezza.
